# CatRaising

Unity 6 기반 고양이 수집·성장 게임입니다. 메인 필드 자동 전투, 4마리 레이드, 고양이 3종을 편성하는 타워 디펜스 던전과 뒤끝 기반 저장을 구현했습니다.

2026-11-10 기준 핵심 플레이 흐름 구현 후 마무리 검증 단계입니다. 튜토리얼·효과음·씬별 반복 BGM을 연결했으며, 모든 BGM의 기본 음량은 기존의 30%입니다. 출시·실기기 검증 완료 상태는 아닙니다.

- Unity 버전: `6000.6.0f1`
- 시작 씬: `Assets/Scenes/LoadingScene.unity`
- 서버 없는 UI·메인 전투 미리보기: `GameScene` 단독 실행
- 공통 리소스: `Assets/Resources`
