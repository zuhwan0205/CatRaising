# 기본 두발 고양이 시안

Built-in image_gen으로 생성한 투명 PNG 스프라이트 시트 시안입니다. 기본 고양이(cat_starter)의 전투 이미지로 연결했습니다. 다른 캐릭터는 기존 이미지를 유지합니다.

4열 × 3행, 위에서부터 대기 / 걷기 / 앞발 공격, 각 4프레임. CatCharacterVisual에서 행별 발바닥 기준점으로 잘라 대기/걷기/공격을 재생합니다. 좌우 방향은 반전으로 표현하며 별도 후면 프레임은 없습니다. Unity 텍스처 필터는 Point, 압축 및 mipmap은 끔.

## 생성 프롬프트

Create one production-oriented pixel art sprite sheet for a cute bipedal orange tabby starter cat in a cozy fantasy action game. Original design inspired by the general small cute retro pet-cat sprite aesthetic, not a copy of any asset. Genuine transparent background. EXACT uniform grid: 4 columns by 3 rows, 12 equal square cells. Canvas 1536 wide x 1152 high. No text, labels, grid lines, frames, ground or shadows. Each cell has the SAME cat at identical scale, consistent baseline 82% down each cell, full body safely inside cell with generous padding. True crisp chunky pixel art, limited 12-color palette, dark brown pixel outline, no gradients, no antialiasing. Each cat visually resembles a 48x48 pixel sprite enlarged with nearest-neighbor. Big round head, two triangle ears, orange stripes, cream muzzle and belly, dark eyes, short upright torso, two short hind legs standing upright and two front paws used as arms, curved tail. No clothes or weapons. All frames face screen-right in a three-quarter front view. Row 1 (idle loop): neutral standing on TWO feet, inhale subtle rise, blink slight squat, return neutral; front paws rest near belly. Row 2 (biped walk loop): left foot forward right arm forward, passing pose, right foot forward left arm forward, passing pose; clearly walks on TWO hind legs, NEVER quadruped. Row 3 (melee paw attack): windup front paw pulled back, forward paw punch swipe extension, full follow-through with three short cream pixel slash marks near paw, recovery to idle. Keep character identity and positions extremely consistent, limb movement readable and coherent. This is a spritesheet asset, not a presentation board.
