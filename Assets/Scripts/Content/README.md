# 캐릭터와 유물 관리

## 구성

- `CatCharacterAsset`: 캐릭터 한 종류의 공통 설정. ID, 이름, 설명, 등급, 아이콘, 기본/레벨당 스탯, 공격 ID, 사거리.
- `CatRelicAsset`: 유물 한 종류의 공통 설정. ID, 이름, 설명, 등급, 아이콘, 효과 ID, 발동 조건, 확률, 수치/레벨당 증가, 쿨다운.
- `CatGameCatalog`: 에셋 목록과 ID 조회. 기존 인라인 목록은 호환을 위해 남겼으며 개별 에셋이 우선합니다.
- `CharacterAttack`: 단일/주변 공격의 대상 선택. 전투 컨트롤러는 피해, 사망, 보상을 처리합니다.
- `RelicEffectRunner`: 보유 및 장착 여부 확인, 확률, 쿨다운, 효과 실행. 설정 에셋에 전투 중 상태를 쓰지 않습니다.
- `CatGameSession`: 유물 장착/해제 및 뒤끝 저장. 최대 3개, 저장 실패 시 장착 상태 복원.

DB 구조와 기존 ID는 그대로입니다. 유저 DB에는 보유 ID/레벨/조각과 장착 ID만 저장하며 공통 설정은 저장하지 않습니다.

## 바로 테스트

1. Unity가 새 파일을 임포트한 뒤 GameScene을 직접 열고 Play합니다.
2. CatGameScene의 Catalog가 비어 있으면 Resources/DefaultCatCatalog를 자동으로 사용합니다. 기존 Catalog가 지정되어 있다면 예제 카탈로그를 직접 연결하거나 그 카탈로그의 에셋 목록에 예제를 등록합니다.
3. Preview Sample Content가 켜져 있으면 로그인 데이터가 없는 씬 단독 미리보기에서만 고양이 2종과 유물 2종을 보유합니다. 로그인된 계정에 테스트 아이템을 지급하지 않습니다.
4. 캐릭터 메뉴에서 기본 고양이/회전 고양이를 선택하고 모험에서 비교합니다.
5. 유물 목록에서 유물을 눌러 장착합니다. 발톱은 명중당 +2 피해, 방울은 피격 후 HP 3 회복(2초 쿨다운)입니다. 목록으로 돌아가 장착 표시를 확인합니다.
6. 로그인 계정에서는 실제 보유한 유물만 장착할 수 있고 기존 BACKND.Database 저장 경로를 사용합니다. 장착 후 재로그인해 유지되는지 확인합니다.

## 콘텐츠 추가

Project 창에서 Create > Cat Raising > Character 또는 Relic을 선택합니다. 고유하고 변경하지 않을 ID를 입력하고 Game Catalog의 Character Assets / Relic Assets 목록에 에셋을 추가합니다. 카탈로그 등록은 보유/지급과 별개입니다.

공격 ID:
- `claw_melee`: 가장 가까운 적 한 마리.
- `spin_melee`: 사거리 안의 모든 적. 여러 처치의 골드는 합산해 한 번 저장합니다.

효과 ID:
- `bonus_damage`: OnAttack이면 해당 공격의 각 대상에, OnHit이면 명중 대상마다 추가 피해. 추가 피해가 새 트리거를 만들지 않습니다.
- `heal`: 자신 회복. 최대 HP를 넘지 않으며 사망한 캐릭터는 부활시키지 않습니다.

트리거는 OnAttack(공격 1회), OnHit(명중 대상별), OnDamaged(살아남은 접촉 피해), OnKill(처치별)입니다. bonus_damage는 OnAttack/OnHit만 지원합니다. 확률은 0~1입니다. 쿨다운은 유물별이며 메뉴/저장 대기 동안 멈추고 장착을 바꿔도 남아 있습니다. 씬을 다시 만들면 초기화됩니다.

기존 Duration Seconds / Max Stacks는 향후 지속 효과용 필드로 아직 사용하지 않습니다. 아이콘 참조는 설정에 보관하지만 현재 UI의 고양이 그림/전투 아트는 기존 임시 표현입니다. 투사체, 화상, 보호막, 골드로 직접 구매하는 획득 기능은 아래 상점 절을 참고하세요.

## 검증

C# 전체 컴파일 및 순수 로직 테스트: 회복 제한/사망, 장착 저장 실패 복구, 중복 요청, 소유권, 슬롯 제한, 유물 성장/중복 ID/트리거/쿨다운/확률 0. Unity 렌더링과 서버 연결은 Play 확인이 필요합니다.


## 캐릭터·유물 레벨업

상세 화면 하단의 레벨업 버튼으로 골드를 소비합니다. 기본 비용은 `20 + (현재 레벨 - 1) × 10`, 최대 레벨은 100입니다. 각 에셋 Definition > Growth에서 Max Level, Base Gold Cost, Gold Cost Per Level을 변경합니다. UI와 저장 기능이 같은 비용 계산을 사용합니다.

캐릭터는 Stats Per Level, 유물은 Effect Per Level만큼 성장합니다. 캐릭터 최대 HP가 늘 때 현재 HP 비율을 유지합니다. 유물 확률/쿨다운은 레벨에 따라 변하지 않습니다. 저장 중 중복 요청과 보상 저장 대기 중 강화를 막으며, 저장 실패/예외가 발생하면 골드와 레벨을 함께 복원합니다. 기존 wallet/characters/relics 데이터에 저장하므로 DB 컬럼 추가는 필요 없습니다.

확인: 모험에서 골드를 모은 뒤 캐릭터/유물 상세에서 강화하고 수치와 잔액을 확인합니다. 로그인 상태에서는 재로그인하여 유지되는지 확인합니다. 미리보기에서는 서버에 저장하지 않습니다.


## 골드 상점

상점 탭 → 상품 → 가격이 표시된 구매 버튼으로 획득합니다. 회전 고양이는 100골드, 발톱/회복 방울은 각각 50골드입니다. 획득 레벨은 1이며 캐릭터 선택/유물 장착은 각 메뉴에서 진행합니다. 보유 항목은 중복 구매할 수 없습니다.

각 Character/Relic 에셋의 Definition > Shop에서 Available과 Gold Price를 설정합니다. 판매 가능 상태이며 가격이 양수인 항목만 표시합니다. 개별 에셋과 기존 인라인 목록은 동일 ID를 중복 표시하지 않으며 개별 에셋이 우선입니다. 새로 만든 에셋은 기본적으로 판매하지 않습니다.

골드 차감과 보유 항목 추가는 기존 player_save 저장 요청 하나로 처리합니다. 저장 실패 시 둘 다 복원합니다. DB 컬럼 변경은 없습니다. 구매 중 중복 입력과 미저장 전투 보상이 있는 동안의 구매를 차단합니다.

씬 단독 구매 테스트는 CatGameScene의 Preview Sample Content를 끄고 Play하세요. 켜 두면 예제를 이미 보유하여 구매할 수 없습니다. 모험에서 골드를 모은 뒤 상점에서 구매합니다. 로그인 테스트는 보유 목록 확인과 재로그인 후 잔액/보유 상태 유지까지 확인하세요. 무작위 뽑기와 중복 조각 획득은 아직 포함하지 않습니다.

신규 유물은 유물 상점에서 구매한 후 유물 메뉴에서 장착합니다(최대 3개 유지). 자동 지급하지 않습니다. 피격 회복은 치명상을 막거나 부활시키지 않으며, 모든 회복은 최대 HP까지만 적용됩니다. 명중 트리거는 대상별로 평가하고 쿨다운은 해당 유물 전체에 공유합니다. 피해 효과끼리는 합산하며 추가 피해가 추가 발동을 유발하지 않습니다.

가격·성장 수치·확률·쿨다운은 초기 테스트 설정으로 개별 에셋에서 변경할 수 있습니다. 신규 전용 아이콘/이펙트는 없습니다. 별도 Catalog 사용 시 Relic Assets 목록에도 등록하세요. DB 구조와 기존 보유 데이터는 그대로입니다.
