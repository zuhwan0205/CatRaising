# 생존 시간별 몬스터

전투 진행 시간 기준으로 0초 먼지 뭉치, 60초 도둑 생쥐, 120초 털실 슬라임, 180초 깡통 게를 누적 해금합니다. 처음 총 4마리로 시작해 30초마다 2마리씩 늘고 9분에 최대 40마리에 도달합니다. 새 종류 해금 시 해당 종류를 추가하고 3분 이후 추가분은 종류별 순환 배정합니다. 처치된 개체는 같은 종류로 재등장하므로 재등장 대기 중 실제 생존 수는 목표 수보다 적을 수 있습니다. 플레이어 사망 시 시간 0 및 전체 적 비활성화, 부활 시 먼지 뭉치만 다시 등장합니다. 저장 등으로 전투가 Blocked되거나 앱이 중지된 시간은 제외합니다. 다른 탭에서 진행 중인 전투는 포함합니다.

MonsterArt의 4열 2행 시트를 이동/피격 모션에 연결했습니다. 종류별 능력치(HP / 이동 속도 / 접촉 피해 / 방어): 먼지 4 / 0.7 / 2 / 0, 생쥐 6 / 1.8 / 3 / 0, 털실 24 / 0.8 / 4 / 0, 게 14 / 0.6 / 5 / 2. 방어는 피해에서 차감하며 최소 피해는 1입니다. 접촉 간격은 기존 0.75초를 유지하고 여러 적과 접촉하면 가장 높은 접촉 피해를 한 번 적용합니다. 둔화는 각 종류의 이동 속도에 0.6을 곱합니다. 처치 보상은 먼지 뭉치 10, 도둑 생쥐 15, 털실 슬라임 25, 깡통 게 40골드입니다. 한 공격에서 여러 종류를 처치하면 각 보상을 합산해 한 번 저장합니다.
