# 2.5D 필드 이동

GameScene 실행 시 CatGameScene이 필드와 UI를 자동 연결합니다. Inspector 추가 설정은 필요하지 않습니다.

- 자동 모드(기본): 가장 가까운 파란 테스트 표적에 접근하고 1.5 거리에서 정지합니다.
- 수동 모드: WASD/방향키 또는 화면 왼쪽 아래 조이스틱. 대각선 속도는 제한됩니다.
- 오른쪽 위 이동 모드 버튼으로 전환합니다. 전환 시 조이스틱 입력을 초기화합니다.
- 이동 속도 3, 이동 경계 x/z ±18. 필드는 40×40 크기입니다.
- 카메라가 고양이를 따라갑니다. RenderTexture를 UI의 필드 영역에 표시합니다.
- 다른 탭에서도 자동 이동/전투/골드 획득이 계속됩니다. 모험 탭 밖에서는 필드 카메라 출력과 수동 입력만 끕니다. 수동 모드는 제자리에서 자동 공격하며 이동 모드는 복귀 후에도 유지됩니다. 앱이 비활성 상태이면 기존처럼 필드를 일시정지합니다.

## 역할

CatFieldController: 필드/임시 스프라이트/표적/렌더 카메라 생성과 수명 관리.
CatMovementController: 수동 입력/자동 목표 선택/이동/경계 제한.
CatCameraFollow: 50도 기울인 직교 카메라 추적. Tilt/Distance로 각도와 거리를 조절합니다.
FieldBillboard: 발 위치를 유지하면서 카메라를 향하는 2D 그림과 앞뒤 정렬.
FieldJoystick: 단일 포인터 조이스틱 입력과 해제.
CatGameSceneUI: 필드 영상, 전환 버튼 및 조작 안내.

적 추적/자동 공격/피해/골드 지급이 연결되어 있습니다. 모드와 위치는 세이브에 저장하지 않습니다. 기존 고정 대상 AutoBattle 초안은 제거했습니다.

## 확인 순서

1. GameScene Play 후 자동으로 표적에 접근하고 멈추는지 확인.
2. 수동 모드로 바꾸고 WASD/방향키로 이동. Game 뷰에 포커스를 둡니다.
3. 조이스틱 드래그와 영역 밖 포인터 해제 후 정지 여부 확인.
4. 자동으로 바꾸면 새 위치에서 가까운 표적을 향하는지 확인.
5. 탭 이동 후 복귀 시 모드 유지/입력 초기화 확인.
6. 필드 경계를 넘지 않고 캐릭터가 카메라 중앙에 유지되는지 확인.

SDK/Unity 참조 C# 컴파일은 통과했습니다. Unity 화면/입력 실행 검증은 아직 수행하지 않았습니다.

바닥은 XZ 평면에 눕힌 스프라이트 표면이고, 캐릭터는 2D 빌보드입니다. 완전한 3D 캐릭터 모델이나 조명/실시간 그림자는 사용하지 않습니다. 그림자는 바닥에 배치한 임시 스프라이트입니다. 카메라 회전(Yaw)은 현재 0도로 고정되어 화면 오른쪽/위 입력을 월드 X/Z 방향에 대응시킵니다.

## 자동 공격 및 접촉 피해

FieldCombatController가 적 4마리의 추적과 XZ 거리 판정을 처리합니다. 사거리 1.7 내 가장 가까운 적에게 선택 캐릭터의 기본 공격력/공격 속도로 할퀴기를 실행합니다. claw_melee 단일 공격과 spin_melee 범위 공격, 장착 유물 효과를 지원합니다. 장비 효과는 아직 미적용입니다. 적 HP는 14, 처치 보상은 골드 10, 적 재등장은 2초 후입니다. 보상은 즉시 DB 저장하며 실패하면 저장 버튼으로 재시도할 때까지 전투를 정지합니다.

접촉 거리 1.05 이내에 살아있는 적이 있으면 고양이는 0.75초마다 max(1, 5 - 기본 성장 방어력)의 피해를 받습니다. 적 여러 마리에 닿아도 같은 간격 안에 중복 피해를 받지 않습니다. 실제 Collider가 아닌 XZ 거리 기반 접촉 판정입니다. HP와 방어력은 카탈로그 기본값 + 레벨 성장값을 사용합니다.

HP=0이면 이동/공격/적 추적이 멈추고 3초 후 중앙에서 체력을 회복합니다. 적도 주변으로 재배치하며 1초의 피격 유예를 줍니다. 캐릭터 변경 시 남은 HP 비율을 유지하며, 전투 HP는 서버에 저장하지 않습니다.

FieldCombatEffects는 카메라를 향하는 세 줄 할퀴기와 공격 순간 크기 변화, 붉은 피격 표시를 처리합니다. 이펙트는 재사용하며 피해 판정 코드와 분리했습니다. HP는 캐릭터 머리 위와 화면 상단에 표시됩니다.

컴파일과 체력 단독 테스트(점진 피해, 사망 1회, 회복, 잘못된 피해, 초과 피해)를 통과했습니다. 실제 Unity의 접촉/이펙트/재등장과 서버 보상 저장은 실행 검증이 필요합니다.


## 탭 밖 전투 확인

자동 모드로 모험을 시작하고 상점/캐릭터/유물 탭에서 기다리면 헤더의 골드가 증가합니다. 모험 복귀 시 진행 중인 위치/HP/적 상태를 그대로 봅니다. 수동 모드에서는 모험 탭 밖의 키보드와 조이스틱 입력을 무시하지만 적 추적과 자동 공격은 계속됩니다.

보상 저장, 구매, 레벨업, 장착 저장은 기존 세션의 단일 저장 잠금을 사용합니다. 저장 요청 동안에는 전투와 변경 입력을 잠시 멈추어 골드 차감과 처치 보상이 충돌하지 않게 합니다. 저장 실패 시 기존 복구/재시도 동작을 유지합니다. 앱 최소화/포커스 상실 시 전투를 계속하는 기능이나 오프라인 보상은 이번 변경에 포함하지 않습니다.


## 구조물과 필드 입체감

FieldScenery가 고양이 집 2개, 석탑 2개, 상자 2개, 나무 16개를 생성합니다. 기존 격자를 흙길·징검돌·잔디 패턴으로 교체했습니다. 구조물은 지붕/측면 명암과 바닥 그림자를 가진 스프라이트 조합이며, FieldBillboard의 발 위치 정렬을 사용해 캐릭터/적과 앞뒤로 겹칩니다. 실제 3D 모델이나 실시간 조명은 사용하지 않습니다.

FieldNavigation은 구조물마다 원형 바닥 영역과 캐릭터 반경 0.42를 사용합니다. 정적 격자 경로망을 만들고 이동 목표별 거리장을 최대 8개 캐시합니다. 자동 이동과 적 추적은 장애물을 우회하며 수동 이동은 경계에서 멈추거나 미끄러집니다. 이동 선분 전체를 검사하므로 큰 이동량에서도 구조물을 관통하지 않습니다. 구조물에 가려진 대상은 접촉/공격 판정에서 제외하고 적 재등장 시에도 빈 위치를 선택합니다.

배치/크기/색상은 FieldScenery.Build 및 House/Tree/Tower/Crate에서 조절합니다. 구조물을 추가할 때 Structure 메서드를 사용하면 충돌 영역도 등록됩니다. 구조물이 동적으로 변경된다면 Navigation.Bake를 다시 호출해야 합니다.

확인 순서: 모험에서 길과 구조물이 보이는지 확인 → 수동으로 집/나무 앞뒤를 이동해 가림 확인 → 벽 쪽 이동 시 통과하지 않는지 확인 → 자동 모드에서 우회 추적 확인 → 다른 탭에서도 전투/보상 유지 확인. 컴파일 및 독립 이동 검증(선분 충돌, 시야 차단, 장애물 우회, 실제 배치의 무작위 70개 이상 경로)은 통과했습니다. Unity 화면 렌더링/Play 검증은 별도로 필요합니다.


## 기본 고양이 아트 비교

현재 모든 캐릭터의 공통 임시 외형으로 CatStarterIsometric.png의 투명 스프라이트를 사용합니다. 위에서 비스듬히 보는 머리/등과 따뜻한 윗면·어두운 측면 명암이 포함됩니다. 선택 캐릭터의 ID/능력치/공격 방식은 그대로이며 외형만 공유합니다.

CatCharacterVisual은 실제 위치 변화를 읽어 상하 흔들림, 작은 기울기/늘어남, 좌우 반전을 적용합니다. 프레임별 발 애니메이션이나 상하 방향별 스프라이트는 아직 없습니다. 발밑 타원 그림자는 바닥에 고정하며 HP 바는 피격 확대/걷기 변형과 별도입니다. 공격 확대/피격 색상은 기존 FieldCombatEffects가 몸 계층에만 적용합니다.

GameScene Play → 모험에서 현재 선택된 캐릭터의 새 그림과 자동/수동 이동을 비교하세요. PNG 투명 채널과 C# 컴파일은 확인했습니다. Unity 실제 화면은 Play 확인이 필요합니다.


## 앞발 공격과 방향 전환

CatCombatFrames.png는 2×2 시트입니다. 위 행은 정면 대기/앞발 공격, 아래 행은 후면 대기/앞발 공격입니다. 좌측 방향은 좌우 반전합니다. 모든 캐릭터의 공통 임시 아트에 적용됩니다.

FieldCombatController.AttackStarted는 공격 1회에 한 번만 발행하며 가장 가까운 공격 대상을 향합니다. CatCharacterVisual은 0.32초 동안 대기 → 앞발 뻗기 → 복귀를 표시하고, 대상 방향으로 몸을 조금 내밉니다. 공격 후 0.45초 동안 시선을 유지하여 걷기 방향과 충돌하지 않게 했습니다. 이동/피해 판정 위치와 HP 바는 움직이지 않습니다. 정면/후면과 좌우 반전 조합의 4방향 표현이며 완전한 8방향 애니메이션은 아닙니다.

Play를 다시 시작해 적이 앞/뒤/좌/우에 있을 때 바라보는 방향과 앞발 움직임을 확인하세요. 이미지 임포트 문제가 있으면 Play 종료 후 Cat Raising > Repair Cat Artwork Import를 사용합니다.
