# Unity에서 UI 직접 편집하기

특별 상점은 이제 프리팹에서 직접 편집합니다. `Assets/Scripts/Resources/SpecialShop`의 View/Card/Popup 프리팹과 Catalog 에셋을 사용하세요. 상품 제목·수량·가격은 Catalog, 배치·폰트·색은 프리팹에서 수정합니다. 아래 런타임 디자인 저장 방식은 아직 프리팹으로 전환하지 않은 나머지 UI에 사용합니다.

## 씬에 이미 있는 UI
Play가 꺼진 상태에서 Game Canvas 또는 Login Canvas 내부 오브젝트를 선택하고 Rect Transform / Image / Raw Image / Text를 수정한 뒤 씬을 저장합니다. 기존 내비게이션 아이콘 크기, 설정 버튼 위치, 재화 행 위치·색을 반복해서 기본값으로 되돌리던 코드를 수정했습니다.

## 실행해야 보이는 상점·팝업
1. Play를 누르고 수정할 화면이나 팝업을 엽니다. 열림 애니메이션이 끝난 뒤 Pause로 멈춥니다.
2. Hierarchy에서 수정할 UI를 선택합니다. 화면 클릭이 어렵다면 Scene 뷰와 Rect 도구를 이용합니다.
3. Inspector에서 위치, 크기, 색상, 폰트 크기, 이미지 등을 바꿉니다.
4. 선택한 UI에 대해 `CatRaising > UI 디자인 > 선택 UI 디자인 저장 (하위 포함)`을 누릅니다. 필요한 최소 영역만 선택하면 좋습니다.
5. Play를 종료하고 다시 실행하여 확인합니다. 수정 사항은 Resources/UIDesignOverrides.asset에 저장되므로 Play 종료로 사라지지 않습니다.
6. 제목·버튼의 글자 내용도 바꾸려면 해당 Text 하나를 선택하고 `선택 Text 고정 문구 저장`을 별도로 누릅니다. 일반 디자인 저장에는 글자 내용이 포함되지 않습니다.

## 저장되는 항목
RectTransform의 위치·크기·앵커·피벗·스케일, Graphic 색, Text 폰트·크기·정렬·Best Fit, 프로젝트에 저장된 Image 스프라이트와 RawImage 텍스처·UV, AspectRatioFitter 설정.
재화 수량, 레벨, HP, 계정 정보, 버튼 클릭 이벤트, 활성 여부, 구매 가능 여부는 디자인으로 저장하지 않습니다. 실시간 값에는 고정 문구 저장을 사용하지 마세요. 런타임에 생성된 스프라이트·렌더 텍스처는 프로젝트 에셋이 아니므로 이미지 교체로 저장하지 않습니다.

## 주의할 점
- 자동 배치(Layout Group), 비율 유지(Aspect Ratio Fitter)가 제어하는 위치·크기는 Rect Transform만 바꾸어도 다시 계산됩니다. Fitter는 해당 컴포넌트 설정을 수정하고 저장할 수 있습니다. Layout Group의 열 수·간격 등은 이 저장 기능의 대상이 아닙니다.
- Safe Area와 Canvas 자체의 배치는 화면 크기에 맞게 자동 제어합니다.
- Hierarchy 이름과 부모 구조는 코드의 연결 경로입니다. 이름 변경, 삭제, 부모 이동, Button/스크립트 제거는 이 기능으로 지원하지 않습니다. UI 구조 자체를 프리팹으로 전환한 것은 아닙니다.
- 저장한 디자인이 씬 편집보다 우선합니다. 되돌리려면 `선택 UI 저장 디자인 삭제 (하위 포함)`을 누르고 화면을 다시 엽니다. 저장/삭제는 Undo를 지원합니다.
- 선택 상태 색, 비활성화 색, 애니메이션, 실시간 텍스트 등 게임 상태에 따라 바뀌는 값은 계속 게임 코드가 관리합니다.
