# 게임 코드 패턴 안내

기존 전투 수치와 저장 데이터 형식은 유지하며, 변경이 자주 생기는 부분만 분리했습니다.

## 전투 상태 전환

`Combat/Core/BattleFlowState.cs`에서 던전의 준비·전투·웨이브 종료·완료 상태와 별도 전투 씬의 일시정지·결과 처리·복귀 상태를 관리합니다. 실제 UI 표시와 씬 이동은 기존 담당 클래스에 남아 있습니다. 잘못된 순서의 호출이나 중복 완료 처리는 상태 객체가 거부합니다.

## 공격 범위 전략

`Combat/Core/AttackAreaStrategies.cs`의 원형·전방·원뿔 판정을 `CharacterCombatRules`가 공유합니다. 공격마다 새 전략 객체를 만들지 않습니다. 슬로우·방어력 감소와 무희의 공격력 버프는 캐릭터 정의의 `hitEffect`, `grantsAttackAura`로 지정합니다. 던전의 투사체 사용 여부는 `delivery`로 지정합니다.

캐릭터 정의는 `Content/Resources`의 기존 캐릭터 에셋에서 편집할 수 있습니다. 공격 이펙트의 외형을 선택하는 코드는 별도로 유지했습니다.

## 이미지 설정과 공유 캐시

`Resources/CatVisualCatalog.asset`에 고양이별 이미지 경로, 프레임 영역, 기준점, 크기 정보를 저장합니다. 이미지 자체를 모두 참조하지 않고 경로만 저장하여 필요한 고양이의 시트를 불러옵니다. `CatAnimationFrames`는 만들어진 프레임을 공유합니다.

`Editor/GameplayPatternMigration.cs`는 기존 설정을 처음 한 번 옮깁니다. 이미 만들어진 이미지 설정은 덮어쓰지 않으며, 전투 특성은 버전 값이 없는 정의만 변환합니다. `LegacyCatFrameMigration`은 변환 및 이전 프레임과의 비교 검사용이며 게임 빌드에 포함되지 않습니다.

## 되돌릴 수 있는 데이터 변경

`GameScene/Session/ReversibleMutation.cs`는 변경 전 값을 보관하고 저장 성공 시 확정하며 실패 시 역순으로 복구합니다. 세션의 구매·강화·선택·스킬·뽑기에서 같은 처리 순서를 사용합니다.

서버 닉네임 변경과 미저장 보상은 성격이 다르므로 기존 전용 처리를 유지합니다. 로컬 복구는 서버 측 거래 기능을 대신하지 않습니다.

## 검증

Unity 배치 모드에서 `GameplayPatternChecks.Run`을 실행하면 상태 전환, 기존 공격 범위와의 일치, 12종 160프레임의 좌표·기준점·크기 일치, 캐시 공유, 저장 실패 복구와 중복 요청 방지를 검사합니다.

`EncounterSceneChecks.Run`은 서버에 접속하지 않는 미리보기 데이터로 실제 플레이 모드에서 던전·레이드 입장, 일시정지, 결과 처리, 보상 중복 방지, 메인 복귀 및 이벤트 구독 정리를 검사합니다. 두 검사는 실행 완료 후 에디터를 종료하므로 별도 배치 프로세스에서 실행합니다.
