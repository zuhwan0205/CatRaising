# CatRaising 개발 현황

기준일: 2026-11-10 (Asia/Seoul). 로컬 코드·에셋과 개발 대화 기준입니다.

## 현재 단계

핵심 플레이 흐름 구현 후 마무리 검증 단계입니다. 구현 완료와 출시 준비 완료를 구분합니다. 오늘 변경한 BGM·리소스 이동은 현재 작업 트리 기준이며 원격 저장소 반영을 확인한 상태는 아닙니다.

| 영역 | 현재 구현 |
|---|---|
| 진입·저장 | 뒤끝 로그인, 데이터 로드·저장, 변경 실패 복구, 미저장 전투 보상 저널 |
| 메인 전투 | 자동 공격, 자동·수동 이동, 생존 시간 기반 몬스터, 경험치 결정 |
| 레이드 | 4마리 편성, 파티 이동, 보스 공격 예고·소환, 결과 처리 |
| 던전 | 3종 편성, 비용 소환, 길 밖 타일 배치, 준비 단계 이동, 웨이브 방어 |
| 성장 | 캐릭터 경험치 레벨·조각 성급·스킬, 유물 골드 레벨·조각 성급·3슬롯 장착 |
| 상점·UI | 최초 해금·확률 뽑기·결과 연출, 프로필·카드·스탯·설정 |
| 특별 상점 | 프리팹·Catalog·Presenter 분리. 가격 버튼 비활성, 실제 결제·보상 없음 |
| 튜토리얼 | 8종 첫 진입 안내, 완료 마스크 저장, 설정에서 다시 보기 |
| 오디오 | 4개 씬 BGM 전환·반복, 기본 음량 0.3, 효과음 풀, 채널별 볼륨·음소거 |
| 성능 | 몬스터·이펙트 풀, 프레임 공유, 공간 검색, 타일맵, 시각 갱신 조정 |

## 11월 10일 반영 내용

- 기존 효과음과 튜토리얼 구현 커밋: `a550f21`, `0b1edb0` (로컬 Git 기록).
- `CatBackgroundMusic` 추가: LoadingBGM / MainBGM / DeongunBGM / RaidBGM 자동 선택, 무한 반복.
- 모든 BGM의 기본 음량을 1에서 0.3으로 축소. 기존 사용자 볼륨·음소거 설정 유지.
- `Assets/Scripts/Resources`를 `Assets/Resources`로 통합하고 에셋 메타 및 에디터 참조 경로 보존.
- 효과음 런타임 경로를 `SFX/`로 수정.
- Docs, README와 노션 프로젝트·포트폴리오 문서 최신화.

| 기기·서버 연동 | 이번 문서 갱신에서 실제 계정·모바일 검증을 수행하지 않음 |

## 마무리 점검

- [ ] Unity 재임포트·컴파일과 이동 에셋의 프리팹·폰트·아트 참조 확인.
- [ ] 로그인 → 메인 → 던전/레이드 → 결과 → 메인 → 로그아웃 왕복.
- [ ] 8종 안내의 최초 표시·완료 저장·다시 보기·일시정지 복원.
- [ ] 4곡 끝까지 청음, 반복 연결부, 씬 전환 중 겹침, 볼륨·음소거·설정 유지.
- [ ] 구매·뽑기·성장 후 재로그인, 저장 실패·앱 종료·미저장 보상 복구.
- [ ] Android 실기기 UI·입력·프레임·메모리·발열 장시간 확인.
- [ ] 플랫폼 로그인과 광고 보상 검증. 특별 상점을 실제 판매할 경우 별도 결제 구현·검증.
- [ ] 재화·뽑기·보상 서버 검증과 아트·음원 출처 정리, 시연 캡처·영상 준비.

기존 검증 도구는 `Assets/Scripts/Editor`에 있습니다. 메뉴의 Combat Target Grid, Field Billboard, Status Sleep, Relic Hot Path, Special Shop Prefabs 검사와 배치용 EncounterSceneChecks/ SpecialShopPlayChecks를 목적에 맞게 실행합니다. 체크 도구가 존재한다는 사실은 이번 실행의 통과 근거가 아닙니다.
