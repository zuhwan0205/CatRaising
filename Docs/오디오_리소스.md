# 오디오와 리소스 관리

최종 갱신: 2026-11-10. 코드와 로컬 에셋 기준이며 실제 청음·모바일 검증은 남아 있습니다.

## 씬별 BGM

| 씬 | 파일 (`Assets/Resources/BGM`) | 용도 |
|---|---|---|
| LoadingScene | LoadingBGM.mp3 | 로딩·로그인 |
| GameScene | MainBGM.mp3 | 잔잔한 메인 전투 |
| DungeonScene | DeongunBGM.mp3 | 던전 |
| RaidScene | RaidBGM.mp3 | 레이드 |

`DeongunBGM`은 실제 파일 이름을 그대로 사용합니다. 이름을 바꿀 때는 `CatBackgroundMusic.PlayScene`의 경로도 함께 변경합니다.

`CatBackgroundMusic`은 첫 씬 전에 생성되고 씬 이동 후에도 유지됩니다. 활성 씬이 변경되면 이전 곡을 멈추고 새 곡을 재생합니다. 같은 곡이 재생 중이면 다시 시작하지 않습니다. 매핑되지 않은 씬에서는 정지합니다. 각 곡은 2D AudioSource의 `loop = true`로 반복하며 씬에 별도 BGM 오브젝트를 배치할 필요가 없습니다. 일시정지·안내 화면에서도 BGM은 계속 재생하도록 설정했습니다. 페이드 전환은 구현하지 않았습니다.

## 볼륨 계산

```text
BGM AudioSource.volume = 0.3 × 사용자 BGM 볼륨
최종 배율 = AudioSource.volume × AudioListener.volume
AudioListener.volume = 음소거 시 0, 그 외 0.5
```

사용자 BGM 볼륨 100%일 때 최종 배율은 0.15입니다. 기본 음량만 1에서 0.3으로 줄였으므로 기존 재생 대비 30%입니다. 설정 슬라이더 값을 30%로 고정하거나 MP3 원본을 편집한 것이 아닙니다. 기존 사용자 설정은 유지됩니다.

`CatAudioChannelSource`는 설정 변경 이벤트를 받아 음량을 즉시 반영합니다. `CatLocalSettings`의 Bgm·Combat 볼륨과 전체 음소거는 기기별 PlayerPrefs에 저장됩니다.

## 효과음

`CatSoundEffects`는 `Assets/Resources/SFX`에서 효과음을 읽습니다. 공격·장착·획득·버튼·승패 등의 이벤트에서 호출하며, 전투 8개와 UI 4개의 AudioSource를 재사용합니다. 같은 효과음의 짧은 시간 내 반복 호출도 제한합니다. BGM 설정과 별도의 Combat 채널을 사용하며, UI 효과음도 현재는 이 채널에 포함됩니다.

## 리소스 이동

`Assets/Scripts/Resources`에 있던 에셋과 `.meta`를 기존 `Assets/Resources`로 합쳤습니다. 기존 `DOTweenSettings.asset`은 유지했습니다. 폴더 안의 개별 에셋 GUID를 보존하고 에디터의 프리팹 생성·아트 임포트·UI 디자인 저장 경로를 갱신했습니다. 기존 SFX 폴더 메타는 새 `SFX.meta`로 맞췄습니다.

Unity가 인식하는 경로는 `Assets/Resources`입니다. `Asset/Resourcess`는 사용하지 않습니다. `Resources.Load`에는 `Assets/Resources`나 확장자를 쓰지 않고 `BGM/MainBGM`, `SFX/Button`처럼 입력합니다. `Assets/Scripts/Content/Resources` 등 다른 기존 Resources 폴더는 이번 이동 대상이 아닙니다.

## 교체와 확인

1. Unity Project 창에서 기존 파일을 같은 이름으로 교체하고 `.meta` 참조를 유지합니다.
2. Loading → Game → Dungeon → Game → Raid → Game → 로그아웃 순서로 곡이 맞게 전환되는지 확인합니다.
3. 각 곡의 끝까지 재생하여 반복 연결부의 공백·클릭음을 듣습니다. 반복 설정만으로 원본 MP3의 끝·시작 공백이 제거되지는 않습니다.
4. BGM/효과음 개별 볼륨, 전체 음소거, 재실행 후 설정 유지, 안내·일시정지 중 재생을 확인합니다.
5. 이동한 프리팹·폰트·아트에 누락 참조가 없는지 확인하고 Android 빌드에서도 반복합니다.

이전 작업에서 이동한 추적 에셋 132개와 BGM 경로 4개의 존재를 확인했습니다. Unity 배치 실행은 초기화 assertion 오류로 종료되었습니다. 최신 컴파일 성공이나 청음 완료로 기록하지 않습니다.
